# 🛡️ VocalShield: Real-Time AI Voice Fraud Detection System

VocalShield is a Neural Acoustic Forensics system designed to detect AI-generated synthetic voice deepfakes using CNN-BiLSTM architecture.

## 🛠️ Features
- Mel-Spectrogram & MFCC Acoustic Extraction
- CNN-BiLSTM Hybrid Model
- FastAPI Backend API
